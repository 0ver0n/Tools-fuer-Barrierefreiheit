# Tools für Barrierefreiheit | Accessibility Tools

**Deutsch:** Kostenlose, frei verfügbare Software, die die Bedienung digitaler Angebote für Menschen mit Behinderung erleichtert. Die Projekte entstehen aus praktischen Erfahrungen mit Screenreadern und Sprachsteuerung. Projektinitiator: **Marcel Lörz** (GitHub: [0ver0n](https://github.com/0ver0n)). Mehr über den Hintergrund: [Blind mit dem Kastenwagen auf Reisen](https://www.blindmitwomo.com).

## Projekte

- [ChatGPT-JAWS-Seitenansicht v2.4.0](chatgpt-jaws-seitenansicht/README.md): Chrome-Erweiterung für besser strukturierte ChatGPT-Unterhaltungen mit JAWS. [Installationsanleitung (Deutsch)](chatgpt-jaws-seitenansicht/INSTALLATION.de.md) · [Installation guide (English)](chatgpt-jaws-seitenansicht/INSTALLATION.en.md).

Jedes Projekt enthält seine eigene Lizenz und die entsprechenden Urheberhinweise.

---

**English:** Free, openly available software aimed at improving access to digital services for people with disabilities. These projects are shaped by hands-on experience with screen readers and voice control. Project initiator: **Marcel Lörz** (GitHub: [0ver0n](https://github.com/0ver0n)). Background and project stories: [Blind mit dem Kastenwagen auf Reisen](https://www.blindmitwomo.com) (German-language blog).

## Projects

- [ChatGPT JAWS Page View v2.4.0](chatgpt-jaws-seitenansicht/README.md): A Chrome extension that adds clearer navigation to ChatGPT conversations for JAWS users. [Installation guide (English)](chatgpt-jaws-seitenansicht/INSTALLATION.en.md) · [Installationsanleitung (Deutsch)](chatgpt-jaws-seitenansicht/INSTALLATION.de.md).
