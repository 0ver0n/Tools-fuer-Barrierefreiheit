# Privacy information (English)

**Project:** ChatGPT JAWS Page View v2.4.0 · **Publisher:** Marcel Lörz (`0ver0n`) · **Website:** https://www.blindmitwomo.com

The extension inspects the structure of the currently open ChatGPT page to improve JAWS navigation through messages and controls. Processing takes place locally in the browser. Page and message content may be processed transiently in memory; the extension does not store conversation archives.

Simplified-view and sidebar preferences are stored locally via `chrome.storage.local`. A technical diagnostics report is copied to the clipboard only at the user's request; review it before sharing.

The reviewed source contains no independent network requests, advertising, or external analytics or tracking services. Normal communication between your browser and ChatGPT happens independently of this extension and is subject to that service's terms.

Scope: `https://chatgpt.com/*` and `https://chat.openai.com/*`. Permissions: `storage` for local preferences and `activeTab` to interact with the active tab from the extension popup. Removing the extension or its browser data removes local preferences.

**Project contact:** Public GitHub Issues: https://github.com/0ver0n/Tools-fuer-Barrierefreiheit/issues . Do not post private ChatGPT conversations in public issues.

Updated November 6, 2026. This notice describes the reviewed v2.4.0 source, not other extensions or ChatGPT's own data processing.
